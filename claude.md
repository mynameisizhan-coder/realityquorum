## Stack
- Node 24 (uses built-in `node:sqlite` — no native build). Fastify 5, zod. Run with `tsx`.
- Server port **8791** (8787 is taken on this machine by the headroom proxy); Vite proxies `/api` there.
- Scripts: `npm run dev:all` (vite + server), `npm run dev:server`, `npm test`, `npm run typecheck`, `npm run check` (all three + build), `npm start` (production). Deployment: `DEPLOY.md`.
- DB file: `server/data/realityquorum.db` (gitignored). Uploads: `server/data/uploads/` (private, served only via authed route).
- Gemini is **live** (`server/gemini/real.ts`, REST, no SDK). Key in `.env` (gitignored, loaded by `process.loadEnvFile`). The key works only with the AI Studio endpoint (`generativelanguage.googleapis.com`); Vertex rejects it.
  - Text tasks (category, claims, missions): `gemini-3.5-flash-lite` → `gemini-3.7-flash`. Photos: `gemini-3.7-flash` → `gemini-3.5-flash-lite`. On 429/5xx/timeout (12 s) it tries the next model, then `FallbackGemini` uses the offline mock. Override with `GEMINI_MODEL=a,b`.
  - `gemini-3.8-flash` was returning 503 (overloaded) on 1 Oct 2026; 2.5 models are retired for new users.
  - All output is zod-validated; mission picks outside the pack are dropped; the pack's disconfirmation missions are always added.
  - Prepared demo cases are always seeded with the mock so they are identical every run.
  - Measured: intake suggestion ~2 s; report with one photo ~7–9 s.

## Domain rules (non-negotiable, from plan.md)
1. Reports are private. Departments see `reporterAlias`, never `reporterId`. Only `trust_officer` can reveal identity, and every reveal is audited.
2. Claims are split into scope tiers: `attribution`, `observable`, `origin`, `responsibility`. A `responsibility` predicate can never be Supported without `authorized_inspection` evidence.
3. Decisions are deterministic (`shared/decision.ts`). Gemini produces *observations*, never verdicts.
4. Missions only come from the approved policy pack templates. Role + qualification are enforced server-side.
5. Work orders require operator approval (or a pack's explicit auto-safety rule).
6. A case closes only when the pack's closure evidence requirements are all met. "Resolved" by a department ≠ closed.
7. Related reports are suggested, never merged.
8. Public updates are generated by `shared/redaction.ts`, guarded against identities and unsupported accusations, and need operator publication.
9. Demo/prepared evidence is flagged `demo: true` and labelled as demonstration data.

## API contract
Auth: `rq_session` HMAC-signed cookie. All `/api/*` except `/api/auth/*`, `/api/public/*`, `/api/health` require a session.

| Method | Path | Who | Purpose |
|---|---|---|---|
| GET | /api/health | any | liveness |
| GET | /api/auth/users | any | demo user list for the role switcher |
| POST | /api/auth/demo-login `{userId}` | any | sets session |
| POST | /api/auth/logout | any | clears session |
| GET | /api/auth/me | any | current user or `null` |
| POST | /api/intake/suggest `{route,text,locationId}` | student | Gemini category/urgency suggestion + extracted claims |
| POST | /api/cases (multipart: `data` JSON + files) | student | create private case |
| GET | /api/cases | role-scoped | students: own; staff: their department; operator/trust: all |
| GET | /api/cases/:id | scoped | full case view (redacted per role) |
| GET | /api/cases/:id/related | staff | related-report suggestions |
| POST | /api/cases/:id/evidence (multipart) | reporter/assigned | append evidence |
| GET | /api/cases/:id/files/:fileId | scoped | private file download |
| GET | /api/missions | responder | missions visible to me (with `eligible` + reason) |
| POST | /api/missions/:id/accept | responder | server enforces role + qualification |
| POST | /api/missions/:id/submit (multipart) | assignee | submit mission evidence |
| POST | /api/cases/:id/workorders | operator | approve + create work order |
| PATCH | /api/workorders/:id `{status,note}` | assigned dept | progress / mark resolved |
| POST | /api/cases/:id/closure-evidence | dept/operator | record closure evidence item |
| POST | /api/cases/:id/close | operator | rejected unless closure requirements met |
| POST | /api/cases/:id/reopen `{reason}` | reporter | reopening request |
| POST | /api/cases/:id/reopen/review `{accept}` | operator | accept / decline reopening |
| POST | /api/cases/:id/public-update | operator | create redacted draft from settled predicates |
| POST | /api/public-updates/:id/publish `{text?}` | operator | publish (guarded: 422 if identity/accusation) |
| GET | /api/public/updates | anyone | published redacted updates |
| POST | /api/cases/:id/reveal-identity `{reason}` | trust_officer | audited |
| POST | /api/cases/:id/abuse-flag | operator | flag malicious |
| GET | /api/abuse-queue | trust_officer/operator | reporters over threshold |
| GET | /api/audit | trust_officer | audit log |
| POST | /api/demo/reset | operator | restore demonstration data |

Errors: `{ error: string, code: string }` with HTTP 400/401/403/404/409.
